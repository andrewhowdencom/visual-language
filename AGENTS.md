# Visual Language agent entry point

When designing or implementing an experience using this repository's language, read [guidance/SKILL.md](guidance/SKILL.md) first. Follow its task-specific reading order, use [tokens/palette.json](tokens/palette.json) and [tokens/foundations.json](tokens/foundations.json) for starter values, and run the review in [guidance/review.md](guidance/review.md).

The Markdown files are the source of truth. The website is generated from them. If you change guidance, update the relevant Markdown and verify the site build.
